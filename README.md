# About Ledgerly

### Description
Ledgerly is a self-hosted personal finance analytics tool that ingests bank statement data, normalizes and categorizes transactions, and visualizes spending trends through various dashboards. It’s designed for people who want full control over their financial data, automation, and reporting.

---

### Page Information
| Page | Description |
| --- | ----------- |
| Process & Upload | Upload a bank statement CSV and process transactions into the database. |
| Rules Engine | Create and manage rules that automatically categorize transactions. |
| Dashboard | View charts and summaries of your bank data, with a link to Grafana for detailed insights. |
| Imports | View previously imported statements and delete them if needed. |
| Logs | Review application logs with filtering controls. |

##### **Built for automation, transparency, and full ownership of your financial data.**
